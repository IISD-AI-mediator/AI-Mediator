# 실제 Gemini 2인 여행방 검증

2026-11-27 20:44:04 KST에 시작해 478.3초 만에 최종 상태 `done`을 확인했다. 두 개의 독립된 쿠키 세션으로 로컬 HTTP API에 입장했고, 두 사람이 조회한 전체 공개 발언·판정 이력·최종 여행안이 동일했다.

개인 에이전트와 역할 배정은 `gemini-3.1-flash-lite`, 판정과 활동 검토는 `gemini-3.8-flash`가 맡았다. 제품의 LangGraph 작업자, 기본 토론 시간 45초, 임시 SQLite를 사용했다. 실제 Google 전송 메서드 앞뒤에서 판정·소요 시간·공개 발언 후보를 기록했다.

## 입력한 조건

방장이 대전 출발, 서울 도착, 2026년 12월 5일부터 6일까지, 장거리 이동은 기차로 고정했다.

- **민재** · 당당한 대변인 (8/2/8). “오래된 여행 친구처럼 짧은 반말로 말해. 먼저 리액션 한마디 하고 하고 싶은 일이나 양보를 또렷하게 말해.”

서윤의 추가 요청은 “국립중앙박물관이 서울에 있는지 공개 자료를 찾아서 관람 일정을 제안해 주세요.”였다. 토론 중 시험자가 민재 계정에서 “이번에는 택시 필수 조건을 철회할게. 현지 이동은 대중교통으로 양보하고 내 중요도도 선호로 낮춰 줘.”라는 비공개 지시 한 건을 보냈다. 민재 세션에서 처리 여부를 확인했고, 서윤의 개인 지시 목록은 비어 있었다.

## 공개 결과에서 확인한 동작

- **페르소나 적용** · 각 화자의 자유 입력 원문이 말투 생성 요청에 전달됐다. 생성한 표현은 서윤 3/3건, 민재 1/3건, 판사 5/5건에서 공개됐다. 민재는 첫 제안과 교통 양보 때 값을 넣을 자리인 `{value}` 대신 실제 숙소명이나 교통수단을 직접 써서 형식 검사를 통과하지 못했다. 그 결과 양보 행동은 반영됐지만 두 번 모두 기본 존댓말이 나갔다.
- **발언 검증의 한계** · 서윤의 첫 발언은 기준문에 없던 “사전에 비용을 상세히 검토하는 조건”을 추가했다. 교통 발언에서도 “가장 효율적”이라는 판단을 덧붙였다. 두 문장 모두 의미 검사에서 승인됐다. 민재의 두 번째 숙소 발언에는 “접근성 확실한”이라는 표현이 공개됐지만, 최종 숙소 근거는 다시 확인해야 하는 상태였다.
- **양보와 판정** · 토론 행동 모델이 민재의 지시 1번을 `yield`와 `prefer`로 해석했다. 다음 판사 요청에서 서윤의 대중교통은 필수, 민재의 대중교통은 선호였다. 판사에게는 변경 후 제안이 전달됐고 개인 지시 원문은 전달되지 않았다.
- **요청과 최종안의 차이** · 두 사람 모두 접근성 조건을 입력하지 않았다. 민재 에이전트가 숙소 검색 후 무장애 객실을 권장했고, 판사가 이를 최종 접근성 항목에 ‘합의’로 표시했다. 두 사람이 제출한 필수 활동은 최종 후보로 남았지만 박물관의 장소와 서울 소재를 함께 뒷받침하는 인용을 검증하지 못해 날짜별 활동 두 칸 모두 비었다.
