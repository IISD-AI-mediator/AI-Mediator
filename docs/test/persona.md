### 실행 방법과 범위

저장소 루트에서 아래 명령을 실행한다. WSGI에서 전체 30개가 4.989초, 페르소나 전용 7개가 0.628초에 통과했다. 전송 환경 변수를 지정하지 않고 로컬 HTTP로 실행한 전체 시험도 8.017초에 30개를 통과했다. 건너뛴 시험은 0개였다. [페르소나 시험](../../tests/test_persona.py)

```powershell
$env:TRAVEL_TEST_TRANSPORT = "wsgi"
.\.venv\Scripts\python.exe -B -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -B -m unittest discover -s tests -p test_persona.py -v
```

브라우저에서는 Chrome 157.0.8103.51의 별도 세션 두 개(너비 360px와 1100px)로 같은 방에 입장했다. 방 설정에서 판사를 의장으로, 준비 양식에서는 각자 라디오 진행자와 오랜 친구로 설정해 대중교통을 제안했다. 새로고침 후 양쪽에서 최종 여행안의 `전체 공개 대화`를 열어 두 제안과 판사의 발언을 확인했다. 방 API, 트랜잭션과 그래프는 실제 구현으로 실행했고, Gemini와 검색 응답은 대역으로 제공했다. 실제 제공자가 페르소나를 따르는 빈도와 지연 시간은 측정하지 않았다.
