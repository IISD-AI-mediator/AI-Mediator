# 여행방 독립 검증 기록

2026-11-26에 Windows에서 전체 회귀 시험 12개가 통과했다(6.597초). 발언·마감 경합, 재시도, 작업 임대 복구, 회차 상한의 네 시험을 새 데이터베이스로 다섯 차례 더 실행해 20건 모두 통과했다(19.078초). 앞서 수행한 4인 여행방 20회의 기록도 보존했다. [4인 통합 시험](group-travel.md)

`v1.0.0`을 Python 3.13.9와 PostgreSQL 16.16에서 실행하고 서로 다른 두 Chromium 세션으로 데스크톱과 모바일 화면을 시험했다. 방장이 초대 링크를 공유한 뒤 두 사람이 의견을 제출했고, 파이트 모드에서 방장이 자기 에이전트에게 교통수단 변경을 요청했다. 두 화면에 같은 결과와 식당 출처가 표시됐고, 새로고침 후에도 결과와 두 차례의 결정 기록을 확인했다. 이 브라우저 시험에서는 Gemini와 검색 응답에 고정된 시험 데이터를 사용했다. [브라우저·PostgreSQL 시험](https://github.com/IISD-AI-mediator/AI-Mediator/actions/runs/45858794486)

## 실행 환경과 재현

코드 승인 커밋 `028ee2ec98622d673d15d0695635daf2a5401778`과 릴리스 커밋 `b9b3574b0db1d83391ead3ed36e5e0243259a9e9`의 `travel_app/` Git 트리는 `01683c6c539183d6332416d3f2ecc2b152dae24a`로 같다. 이번에 실행한 `tests/` 트리는 `b882f370cfc75645f96ba685f617117c69e43292`다.

Windows Python 3.13.9 릴리스 작업은 당시 시험 6개를 2.150초에 통과했고 태그 게시 작업도 성공했다. 별도 공개 HTTPS 점검에서는 정적 JS·CSS가 200, 팀 코드 없는 방 개설이 403, `/healthz`가 릴리스 버전 1.0.0·해당 커밋·정상을 반환했다. [릴리스 작업](https://github.com/IISD-AI-mediator/AI-Mediator/actions/runs/45858227230) · [공개 HTTPS 점검](https://github.com/IISD-AI-mediator/AI-Mediator/actions/runs/45859163705/job/140045346324)

로컬에서는 Python 3.11.17, Flask 3.1.1, LangGraph 1.2.15, SQLite 3.53.4를 사용했다. 독립 쿠키를 가진 Flask 클라이언트가 WSGI로 요청을 보냈다. 4인 시험은 실제 스케줄러를, 복구 시험은 같은 컴파일 그래프와 DB를 사용했다. 모델·검색 응답은 고정된 시험 데이터였다. 마감 및 임대 만료는 서버 시계를 앞으로 옮겨 재현했다.

저장소 루트에서 PowerShell로 같은 로컬 시험을 실행한다.

```powershell
$env:TRAVEL_TEST_TRANSPORT = 'wsgi'
python -m unittest discover -s tests -v
python -c "import sys, unittest; s=unittest.TestSuite(unittest.defaultTestLoader.discover('tests', pattern='test_room_recovery.py') for _ in range(5)); sys.exit(not unittest.TextTestRunner().run(s).wasSuccessful())"
```

일반 환경에서는 변수 설정 없이 같은 명령을 실행하면 복구 시험이 Werkzeug HTTP 서버와 서로 다른 쿠키 저장소를 사용한다. 이번 로컬 환경에서는 루프백 TCP 연결이 Windows 오류 10013으로 차단됐다. 실제 데스크톱 브라우저 두 개의 화면·소리·키보드 조작, 실제 Gemini·Google 검색 응답, 배포된 PostgreSQL에서의 다인 협상은 이 독립 시험의 관찰 범위 밖이다.
